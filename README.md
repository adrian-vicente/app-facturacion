# 💰 Personal Finance Manager

> Aplicación web híbrida para la gestión de finanzas personales desarrollada con Angular v21 y Spring Boot.

Controla tus ingresos, gastos, presupuestos, objetivos de ahorro y recibos desde una única plataforma intuitiva y moderna.

---

## 🚀 Características

✅ Gestión de ingresos y gastos

✅ Categorías personalizadas

✅ Objetivos de ahorro

✅ Presupuestos mensuales

✅ Gestión de recibos y facturas

✅ Dashboard financiero

✅ Estadísticas y gráficos interactivos

✅ Autenticación segura mediante JWT

✅ Diseño responsive

## 📊 Funcionalidades

### 💵 Gestión de movimientos

Permite registrar:

* Ingresos
* Gastos
* Concepto
* Descripción
* Fecha
* Importe

### 🏷️ Categorías

Organiza los movimientos mediante categorías personalizadas:

* Alimentación
* Hogar
* Transporte
* Ocio
* Salud
* Mascotas
* Trabajo
* Otras

### 🎯 Objetivos de ahorro

Define metas económicas y realiza un seguimiento del progreso.

Ejemplo:

* Viaje a Japón → 4000€
* Fondo de emergencia → 3000€

### 📋 Presupuestos

Controla cuánto dinero deseas gastar cada mes.

Ejemplo:

* Alimentación → 300€
* Ocio → 150€
* Transporte → 100€

### 🧾 Gestión de recibos

Asocia documentos a cada movimiento:

* PDF
* Imágenes
* Facturas
* Tickets

---

## 🔐 Seguridad

La aplicación utiliza autenticación basada en JWT.

Las operaciones se realizan sobre el usuario autenticado sin necesidad de exponer identificadores en el frontend.

---

## ⚙️ Instalación

### Clonar repositorio

```bash
git clone https://github.com/tu-usuario/personal-finance-manager.git
```

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
ng serve
```
